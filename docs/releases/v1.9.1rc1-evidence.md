This is an **owner-approved deviation** from the 48-hour soak target for this

v1.9.0). The shortened window was not extended or rounded up. Rationale: a
narrowly-scoped bugfix (domain-matching logic only, no schema/tool-surface
change) with full green evidence across the Python matrix, MCP floor, Odoo
18/19 playground, and Docker preflight before tagging.

Promotion to stable must not proceed before the minimum end used above, and
the clock resets to zero if any runtime, packaging, dependency, or
workflow-behaviour change lands before then.

## Authorization note: `pypi` environment has no protection rule

`gh api repos/minhhq-a1/odoo-pulse/environments/pypi` returned
`"protection_rules": []` at publish time. `docs/guides/releasing.md` section 6
describes "approving the protected `pypi` environment" as a manual gate, but
no required reviewers are configured, so `publish-pypi` ran straight through
without pausing for approval. This did not block or change this release, but
the manual-approval gate the docs describe is not currently enforced — worth
configuring required reviewers on the `pypi` environment before relying on it
as a checkpoint in a future release.
